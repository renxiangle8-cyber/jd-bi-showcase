# 京东经营 BI · 产品演示

此仓库仅包含公开静态演示站，不包含正式 BI 后端、数据库连接或模型密钥。

- 展示：八个栏目、预设问答、数据筛选、截图画廊、深浅主题。
- 数据：固定真实经营快照经过主体、金额、日期脱敏；不能据此判断实际经营表现。
- 交互：问答和钉钉为预设流程，不会调用模型或向外发消息。
- 财务：缺失项目保留“未提供”，不以 GMV 代算结算利润。

通过 GitHub Pages 发布，使用 `main` 分支根目录。静态文件可直接由任意 HTTP 静态服务托管，全部资源使用相对路径。

视觉与介绍页样式基于 [2689508458/jdbi-showcase](https://github.com/2689508458/jdbi-showcase) 的公开介绍页改造；此处截图来自本项目实际界面的脱敏预览。
